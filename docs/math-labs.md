# 第21—31章：数学实验

这些实验对应书中 M21—M31。各课单独生成玩具数据，用来理解公式、算法和反例；没有使用主线 A 的患者样本，不能把这里的 C、Brier 或校准斜率写进主线 A 的结果表。

先安装科学计算依赖，再在项目根目录运行：

```bash
python -m pip install -r requirements.txt
python run.py math 21 --mode quick
python run.py math 24b --mode quick
python run.py math all --mode quick
```

整数章号会运行该章的所有实验，例如 `math 24` 会运行 `24` 和 `24b`。带 `b` 的编号只运行对应补充实验。输出位于 `outputs/quick/math/<编号>/`：`stdout.txt` 保存完整计算过程；`result.json` 保存实际模式、计算预算、数值验收及关键结果。失败的验收会使程序返回非零状态。第31章的反事实数据是在模拟中生成的，实际观测资料无法直接取得这些潜在结局。

`--mode book` 使用原书的计算预算，并写到 `outputs/book/math/`。直接执行 `math/chXX.py` 时，默认模式为 `book`；建议使用统一命令以保存日志。运行单个 Python 文件前，先切换到自己的输出目录，以免把 `result.json` 写在代码目录。它们没有为正式统计分析自动选择变量、惩罚强度或样本量。

## 实验与验收

| 章 / 编号 | 实际操作 | 应检查的结果 |
|---|---|---|
| 21 | 二乘二表的 IRLS、分离、Firth、FLIC | 无分离的 log OR 为 `log(6)`；FLIC 平均预测为 `4/200=0.02`；分离示例的有限迭代值不能当成有限 MLE |
| 22、22b | 正交惩罚闭式解、坐标下降、收缩模拟、非单调支持反例 | Ridge、Lasso 与闭式解一致；矩条件例的 Lasso 为 `(0.6875, 0.1875)`；每个 Elastic Net 反例检查 KKT 条件 |
| 23 | RCS 基函数、参数量、P样条、非线性检验 | RCS 外尾二阶差为零；系数索引的线性零空间与普通 `x` 直线不同；伪逆协方差正态不是平坦的内蕴先验 |
| 24、24b | Cox 风险集、Breslow 基准风险、Aalen–Johansen、竞争风险 Brier | Cox 得分接近零；两种原因的 CIF 与生存率之和为 1；正确原因1标签的 Brier 为 `0.216389` 与 `0.263333`，错误任何事件标签会反转模型排序 |
| 25、25b | Gini 分裂、二阶提升、OOB、森林与提升的校准网格 | 手工 Newton 树桩与 sklearn 一致；正则化目标下降与二阶近似有差别；增加树的数量不能保证校准斜率改善 |
| 26、26b | 前向、反向传播、有限差分、神经网络正则化网格 | 梯度误差小于 `1e-8`；`20→64→64→1` 含 `5569` 个参数；网格实验是不同随机开发样本的描述性比较 |
| 27 | AUC、DeLong、Brier 分解、积分、校准、NRI | 十人手算 AUC 为 `20/24`；快速与暴力 DeLong 分量一致；单调变换可保持 AUC，同时改变校准与 Brier |
| 28 | 全枚举 bootstrap、CV 方差、筛选泄漏、嵌套验证 | 六人均值模型的乐观值等于 `2σ̂²/6`；CV 协方差恒等式成立；所有 Logistic 拟合通过梯度验收；外层验证与内层最优分数要分开解释 |
| 29 | Rubin 规则、MCAR/MAR/MNAR、PMM、部署补值 | Rubin 总方差为 `0.04914`，SE 约 `0.22168`；PMM 补值来自观测供体；概率的平均一般不等于把均值代入 Logistic 后的概率 |
| 30 | 开发三准则、模型分布假设、外部验证精度 | 三准则取最大并向上取整；较弱模型需要更多开发样本；输出不是 `pmsampsize` 包运行结果，数值不能跨假设直接替换 |
| 31、31b | 病例对照校正、类平衡、IPW、混杂与政策反馈 | 抽样校正涉及截距；足够混杂调整恢复真实系数；普通 IPW 目标 Brier 为 `0.1875`，用 `X` 的条件概率作稳定分子后为 `0.1275`，目标已改变 |

## 快速模式与原书预算

确定性小例保留原计算。快速模式降低下表中的 Monte Carlo 样本量或重复数，因此模拟均值、标准差、功效和覆盖率会变化；较少重复数不适合得出稳定的统计结论。所有实际预算都另存在各课 `result.json` 的 `budgets` 中。

| 编号 | `quick` | `book` |
|---|---|---|
| 22 | Logistic 20 次，测试集 8000 | 400 次，测试集 60000 |
| 22b | 线性重复 300 次 | 6000 次 |
| 23 | 各样本量功效 40 次 | 400 次 |
| 25 | OOB 2000 次；相关树均值 20000 次 | OOB 20000 次；均值 200000 次 |
| 25b | 3 个开发样本，测试集 5000，RF 最大 60 棵 | 20 个，测试集 40000，RF 最大 300 棵 |
| 26b | 3 个开发样本，测试集 5000 | 20 个，测试集 40000 |
| 27 | AUC bootstrap 100；重校准 20000；NRI 50000 | 1000；1000000；2000000 |
| 28 | OLS 重复 200；OLS bootstrap 30×50；噪声 12×20；嵌套 8 次 | 2000；600×200；300×100；150 次 |
| 29 | MI 20 次重复、5 份；PMM 10 次、400 待填者；部署 6 次 | MI 300 次、20 份；PMM 200 次、4000 待填者；部署 60 次 |
| 30 | 开发模拟 10 次、测试集 5000；精度核对 40 次 | 300 次、测试集 100000；600 次 |

第25章原脚本为相关正态树预测构造大协方差矩阵。项目改为直接抽取其均值：均值恰好服从方差 `ρ+(1−ρ)/B` 的正态分布，避免生成数 GB 中间数组。数学分布保持一致，但随机数消耗顺序改变，Monte Carlo 末位不与原书逐位一致。随机森林使用单个工作线程，便于同时运行多课。随机种子仍固定，各原始脚本的 SHA-256 在 `math/catalog.json` 中保留。

## 本地验收与限制

固定依赖为 NumPy `2.0.2`、SciPy `1.13.1`、scikit-learn `1.6.1`，本次实际运行使用 Python `3.9.20`，建议读者安装 Python `3.11` 或 `3.12`。2026年10月11日，全部16个实验分别在 `quick` 和 `book` 模式实际运行成功，每种模式的47项数值验收均通过。公开记录保存于 [math/reference_results.json](../math/reference_results.json)，只包含合成实验的环境、预算和数值，不含真实患者资料。不同 CPU、线性代数库或版本可导致浮点末位变化，解析恒等式用容差判断。

运行回归验收：

```bash
python -m unittest discover -s tests -p test_math.py -v
```

这些测试检查二乘二表、竞争风险标签、反向传播及权重目标等关键反例。森林和神经网络的校准网格包含训练算法、有限开发样本和测试集的随机性；它们不提供全部超参数的全局最优或全部神经网络优化已充分收敛的证明。第28章的选择流程专门包含故意做错的对照，请按标签理解，不能复制错误流程到真实研究。
