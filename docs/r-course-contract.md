# R 实操课程接口与验证边界

`Rscript --vanilla R/lesson_cli.R --chapter 8 --mode quick --output <绝对输出目录>` 执行第 8 章；`--chapter all` 依次执行第 1—20 章。可从任意工作目录执行脚本的绝对路径。CLI 以脚本位置定位项目并加载模块，不依赖读者当前目录。Python 入口使用同一接口。

在已加载模块的 R 会话中，`run_chapter(chapter, output_dir, mode)` 返回状态、章号、模式和产物路径。全部生成数据、缓存、图、表与日志都位于 `output_dir` 内。`data/main_case.csv` 和 `results/model.rds` 的共享前置条件自动生成，不需要按序完成之前的章。模型输入固定为 14 个变量、18 个待估参数。病例 A 为 3200 例合成样本、种子 20261010，30 天 CD ≥ III 包括死亡；数据不是患者资料。

每章目录为 `chapters/chNN/`，包含 `lesson.md`、实际生成的章内产物和 `status.csv`。`manifest.csv` 记录已经执行的章节，两种状态文件沿用相同的七列结构。本次启动先将该章状态置为 `RUNNING`，成功才记 `PASS_EXECUTED`；异常或可处理的中断则写 `FAIL`，在 `scope` 和章目录的 `failure.txt` 中保存实际错误原因。重新运行失败不会继续保留上次成功状态；后续成功重跑会清除该章旧 `failure.txt`。操作系统强制终止可能留下 `RUNNING`，此时仍不能视为完成。模式冲突在写入章状态之前被拒绝，不覆盖另一模式记录。此机制覆盖进入课程函数之后的运行，R 启动或模块载入失败由入口命令的非零退出记录。`PASS_EXECUTED` 只表示该教学练习实际成功执行，不能解释为临床审阅通过。

quick 为快速操作与测试预算，不作为书中标准数值。book 使用正文标准预算；具体版本和平台仍可能造成浮点差异。缓存键包含实际数据摘要、R 版本、模式、预算、预测规则身份和 R 算法源文件摘要（包括校准与竞争风险分支），避免读取旧数据、算法或另一模式的结果。源码缺失时停止，不沿用缺失摘要。哈希临时文件也只写在当前输出的 `cache/` 中。输出目录已属于另一模式时，函数拒绝覆盖。

`development_intervals.csv` 描述内部校正开发统计量的有限预算双重 bootstrap 经验分位数范围；`fixed_model_intervals.csv` 描述固定模型在原开发样本上的表观评价；`calibration_curve.csv` 的带描述固定模型表观平滑曲线的逐点条件经验范围。三者均不能替代固定最终模型的真实外部性能区间。校正校准曲线没有区间带。开发与校准失败不会被静默删除并当作成功结果；固定模型条件范围必须有全部预算次数有效且估计与上下界有限。第 7、10、11、14 章必需的校准或评价指标不可估时，该章停止并记录失败。亚组描述单独使用其已注明的有效次数与 NA 政策。

第 7 章默认实际运行的是**训练中位数填补演示**，不是多重插补，未宣称运行完整 MICE 链。第 10—11 章实际比较和调优 base R ridge Logistic 候选，不复制未交付的森林、boosting 或 TabPFN 历史数字。这里使用事先固定的中心、尺度与年龄结点，没有从样本估计均值或标准差；若扩展为学习型标准化，必须在每个内层训练集重新估计。ridge 接口要求有限设计、首列截距、两类二值结局及严格正的 λ；无惩罚 ML 由有独立失败检查的原模型函数负责。第 14 章使用独立种子与不同事件率的合成验证样本，采用 `V` 前缀 ID 区别开发 `A` 样本；更新和评价分别使用 800 行，不称为临床外部验证。第 17—20 章保留人工 `PENDING`，没有生成签名、发送邮件、投稿或部署。

运行 `Rscript --vanilla tests/test_course.R <绝对 quick 输出目录>` 会真实执行全部 20 章，再核对参考样本数、标签、可得性、单位转换、外层训练、调优范围、反例拒绝、区间目标、更新划分和人工待审状态，生成 `test_summary.csv`。`invalid_input_checks.csv` 记录实际非法标签、负或零惩罚以及常数预测校准失败的拒绝。`failure_status_check.csv` 记录第 8 章已成功后，临时注入拟合错误导致本次章状态与 manifest 同时变为 `FAIL`；随后恢复函数并正常重跑验证恢复。测试还实际检查模式冲突不会覆盖既有状态。这些检查没有证明临床有效性，也没有执行可选完整 MICE 链。
