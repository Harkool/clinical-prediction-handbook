# 学习路径

每个路径都以一次可执行的合成数据流程为基础。运行命令使用同一个 Python 环境；环境准备见 [安装指南](installation.md)。

## 先完成一份可核查结果

```text
python run.py doctor
python run.py course --mode quick
python run.py verify --mode quick
```

打开第 18 章报告，找到数据来源、预测时点、结局计时原点、参数预算、表观表现、内部校正表现和区间目标。再打开第 08 章模型产物与第 13 章图表，核对报告中的数字来自哪张表。

主线 A 使用 3,200 名合成成年人；14 个原始输入构成 18 个非截距参数。预测在术前麻醉评估完成、诱导之前进行，结局从实际手术开始起观察 30 天，CD ≥ III 包括死亡。主线全样本开发，并进行整流程 bootstrap 内部验证。

## 临床读者

按 01 → 04 → 05 → 07 → 18 阅读，和统计合作者运行 02、03、08、12、13。重点回答四个问题：为谁预测、何时预测、预测什么、结果支持多强的结论。

实际练习：把第 04 章六要素用自己的研究问题重新写一遍；为第 05 章列出完整无事件、窗口内事件、提前失访和死亡四种情况；最后在第 18 章报告中逐条指出合成教学结论的范围。模板的签名栏保持待审，直到真实负责人完成审核。

## 统计读者

完成快速课程后按 06 → 07 → 08 → 11 → 12 → 13 → 14 → 15 → 16 阅读，再进入 21—24、27—30 的数学实验。重点核对训练范围、估计目标、重采样中重复的步骤和不确定性来源。

实际练习：追踪第 11 章同一外层折的训练与评价 ID；对照第 12 章两种重抽样区间；在第 13 章图中指出表观曲线条件带与校正曲线点估计；用第 16 章反例检查自己的接口。

## 数据科学读者

先完成 04—07 的时间、标签和输入审查，再按 08 → 10 → 11 → 12 → 13 → 17 阅读。树和网络的原理实验见 25、26 章。

实际练习：确认冻结结构的 Logistic 基线也在外层训练集重新拟合；记录第 11 章每折内层选择的复杂度；在第 17 章试改单位或一个样条结点，检查预测接口是否拒绝。第 10、11 章课程运行 Logistic 候选流程；第 25、26 章另有树和网络的独立数学实验，表格基础模型需另建验证扩展。

## 一次完整的课程作业

按 [逐章指南](chapter-guide.md) 为每章保存一条记录：使用的命令、查看的文件、完成的练习、发现的问题及解释。先用 `quick` 修正理解和接口，再使用 `book` 检查主线预算下的结果。

最终交付一份可复核的学习报告，包含方案、字典、模型与预测、评价图表、实际运行清单、环境记录、失败或未运行项、局限与人工审核状态。第 19 章生成投稿准备材料，第 20 章生成 AI 与人工复核记录；这两章的自动运行不代表完成投稿或人工签审。

## 如何读“通过”

| 状态或证据 | 可以说明什么 |
| --- | --- |
| 命令正常退出 | 声明的代码步骤执行结束 |
| 自动检查 PASS | 该检查范围内的条件符合要求 |
| 负向检查 PASS | 注入的已知错误被指定检查拒绝 |
| 人工审核 PENDING | 仍需真实人员确认，运行器没有代签 |
| 合成新数据上的评价 | 独立数据的验证和更新步骤得到教学演示 |

自动检查及合成实验各有明确范围。真实人群的外部验证、临床影响评价、生产部署和长期监测需要新的数据、方案与证据。
